Orchid / release proposal

Ship a calmer planning workflow

Preserve the document's voice and layout while making review decisions easy to capture.

Outcome

Teams can review the rendered plan without losing typography, hierarchy, or responsive behavior.

The final action list remains precise enough for an agent to apply without guessing.

Delivery stages

  1. Validate the local security boundary and original static layout.
  2. Exercise keyboard navigation, search, links, and every annotation type.
  3. Package the browser application inside the existing single binary.

Open decision

Release all supported platforms on the same day, even if the manual browser checklist is incomplete.

Constraints

  • Markdown continues to use the TUI.
  • HTML review runs only on 127.0.0.1.
  • Document JavaScript never executes.
